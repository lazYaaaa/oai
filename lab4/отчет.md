# Лабораторная работа №4
## Выделение контуров на изображении

**Выполнил: Лазарев Ярослав Б23-514**

Оператор Круна 3x3, формула градиента `G = |Gx| + |Gy|`.

Использованные ядра:

`Gx = [[ 17,  61,  17],`
`      [  0,   0,   0],`
`      [-17, -61, -17]]`

`Gy = [[-17,   0,  17],`
`      [-61,   0,  61],`
`      [-17,   0,  17]]`

Порог бинаризации нормализованной матрицы `G`: `T = 70`.
